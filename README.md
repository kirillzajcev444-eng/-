# Fast db

Демонстрационный модуль асинхронного бэкенда на FastAPI для интеграции с фронтендом.

## Функции
REST API эндпоинты (GET, POST) с версионированием /api/v1/
Строгая валидация входящих JSON-данных через Pydantic-схемы
Анти-дюп (защита от повторного выставления активных лотов)
Автодокументация Swagger (OpenAPI)

## Запуск
1. Запустить сервер: py fastdb.py или py -m uvicorn fastbd:app --reload
2. Открыть интерактивную документацию: [http://localhost:8000/docs#]
